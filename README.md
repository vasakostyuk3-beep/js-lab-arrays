# Лабораторна робота — Об'єкти та масиви JavaScript

**Виконав:** Василь Костюк, №10. **Індивідуальний варіант:** 10 — Колекція відеоігор.

## Реалізовано

1. Об'єкт `book` із властивостями `title`, `author`, `year`, `isRead` та методами `bookInfo()` і `markAsRead()`; зміна `isRead` на протилежне.
2. Масив `library` з трьома початковими книгами, `displayLibrary()`, додавання через `push()`, зокрема за допомогою `prompt()` і `confirm()`.
3. Сортування `sort()` за роком, фільтрація непрочитаних `filter()`, пошук автора J.R.R. Tolkien методом `find()`.
4. `calculateAverageYear()` — середній рік видання.
5. Індивідуальний проєкт «Колекція відеоігор»: назва, платформа, жанр, рік виходу, чи пройдено; додавання, фільтрація, пошук, сортування, зміна статусу.
6. Кнопка демонстрації результатів у журналі та в консолі браузера.

## Запуск

Відкрийте `index.html` у браузері. Для GitHub Pages: завантажте `index.html`, `style.css`, `script.js`, `README.md` у корінь публічного репозиторію, далі **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

## Висновок

Закріплено навички створення об'єктів та масивів, використання методів `push`, `sort`, `filter`, `find`, взаємодії з користувачем через `prompt`, роботи з `this` у методах об'єктів і створення інтерактивного індивідуального проєкту.
